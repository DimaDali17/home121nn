# Квартира 69,5 м² — 3D-модель

Интерактивная 3D-модель квартиры, собранная по рабочим чертежам (план М 1:60): стены, проёмы и окна по размерам, отделка и мебель по 3D-эскизам проекта.

Открыть: https://dimadali17.github.io/home121nn/

- **Обзор / План сверху** — общий вид, вращение мышкой, колесо — масштаб.
- **Встать внутри** — вид из комнаты на высоте глаз; WASD или стрелки — идти.
- **Двойной клик по полу** — встать в эту точку.
- **Срез стен** — макет в разрезе на высоте 1,2 м.

Всё в одном файле `index.html`, библиотека three.js подключается с CDN.
